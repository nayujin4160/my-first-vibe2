# 01 · F1 첫 캡처 올리기

> Vibe Studio · build-spec · 작성일: 2026-10-16
> 목표: UI 구현 · 관련 플로우: F1 · 조각 5개
> 정해둔 것: ../SETUP.md

- [x] **1. 프로젝트 준비 + 시작 → 정리 중** (F1 ①②)
  - 확인: 첫 화면에 "캡처나 영수증을 올리면 날짜·가게·금액을 정리해 둘게요."와 주황 버튼 [캡처 올려보기] 하나만 보인다
  - 확인: [캡처 올려보기]로 사진 4장을 고르면 "캡처 4장 중 2장 읽는 중이에요"처럼 장수가 올라가고, 다 읽은 썸네일에 체크가 붙는다
  - 확인: 사진 고르다 취소하면 시작 화면 그대로다
- [x] **2. 정리 결과 + 줄 고치기** (F1 ③)
  - 확인: 다 읽으면 "전부 공용에 넣었고, 같은 결제 1건은 뺐어요."와 날짜별 목록 12건이 보이고, 줄마다 `공용` 꼬리표가 있다
  - 확인: 줄을 눌러 `용돈`으로 바꾸거나 금액을 고치면 목록에 바로 반영된다
  - 확인: 주소에 `?ocr=none`을 붙이고 올리면 "이 캡처는 금액을 읽지 못했어요."가 보인다 · `?ocr=partial`이면 목록 위에 "1장은 읽지 못했어요"와 [다시 올리기]가 보인다
- [x] **3. 시작하기(계정)** (F1 ④)
  - 확인: [저장할게요] → "정리한 12건을 저장할까요?"와 [카카오로 시작] → 누르면 바로 하루 카드로 넘어간다
  - 확인: 시작하기에서 뒤로 가거나 새로고침하면 정리 결과가 고친 그대로 다시 보인다
  - 확인: `?kakao=fail`이면 "카카오로 시작하지 못했어요. 잠시 뒤에 다시 눌러주세요."가 보이고 넘어가지 않는다
- [x] **4. 하루 카드 + 사진 붙이기** (F1 ⑤)
  - 확인: 가장 최근 날인 10월 14일 카드가 열리고, 그날 내역과 "이날 공용 42,200원"이 보인다 (용돈으로 옮긴 건 합계에서 빠진다)
  - 확인: ‹ 를 누르면 10월 13일 카드로 바뀐다
  - 확인: [+ 이날 사진 붙이기]로 사진을 고르면 그 자리에 사진이 보이고, 새로고침해도 남아 있다
- [ ] **5. 알림 묻기 → 홈** (F1 ⑥)
  - 확인: 첫 하루 카드에서 [달력 보기]를 누르면 "저녁에 알려드릴까요?" 시트가 올라온다
  - 확인: [괜찮아요] → 홈(이번 달 달력)으로 가고, 13·14일을 누르면 그날 카드가 열리며 시트는 다시 뜨지 않는다
  - 확인: [저녁에 알려주세요]를 누르면 화면 안 안내 문구가 보이고 홈으로 간다 · `?notify=blocked`면 "알림이 꺼져 있어요. 설정에서 켜면 저녁에 알려드려요."가 보인다
