# 02 · F2 오늘 거 올리기

> Vibe Studio · build-spec · 작성일: 2026-10-16
> 목표: UI 구현 · 관련 플로우: F2 · 조각 3개
> 정해둔 것: ../SETUP.md

- [ ] **1. 홈 달력 — 달 넘기기와 빈 날** (F2 ①, 하루 카드(F2에서 열 때))
  - 확인: F1을 그대로 마치고 홈에 오면 "2026년 10월"과 "이번 달 공용 230,020원"이 보이고, 오늘(16일) 칸은 테두리로 표시된다
  - 확인: ‹ 를 누르면 9월로 넘어가고 "이번 달은 아직 비어 있어요. 캡처 한 번에 여러 장 올릴 수 있어요."가 보인다 · 10월에서 › 는 흐리게 눌리지 않는다
  - 확인: 기록이 없는 15일을 누르면 "이날은 아직 비어 있어요. 캡처 한 장이면 돼요."와 "+ 직접 추가"가 있는 하루 카드가 열린다
- [ ] **2. 홈에서 오늘 거 올리고 달력이 채워지기** (F2 ①②③④)
  - 확인: 홈의 [캡처 올리기]로 사진을 고르면 정리 중을 거쳐 정리 결과에 "이미 올린 결제 2건은 뺐어요."와 15·16일 결제 4건이 보인다
  - 확인: [저장할게요]를 누르면 카카오를 묻지 않고 홈으로 돌아와 15·16일 칸이 연한 주황으로 잠깐 강조되고, 아래에 채워졌다는 안내가 뜬다
  - 확인: `?ocr=dup`이면 "이미 올린 결제예요. 새로 넣을 내역은 없어요."와 [홈으로]가 보인다
  - 확인: 홈의 "직접 쓰기"로 오늘 결제를 쓰고 저장하면 홈으로 돌아와 16일 칸이 채워지고 이번 달 공용 합계가 늘어난다
- [ ] **3. 설정과 다시 들어오기** (F2 ① 설정, 예외)
  - 확인: 홈 오른쪽 위 톱니를 누르면 설정에 "저녁 알림" 스위치와 "김콩알 · 카카오", "로그아웃"이 보인다
  - 확인: 저녁 알림을 켜고 새로고침해도 켜져 있다 · `?notify=blocked`에서 켜면 "알림이 꺼져 있어요. 설정에서 켜면 저녁에 알려드려요."가 보인다
  - 확인: [로그아웃] 뒤 주소 `/home`으로 들어오면 [카카오로 시작]이 나오고, 시작하면 기록이 그대로 있는 홈이 나온다
