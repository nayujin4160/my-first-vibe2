# Setup — 콩알가계부

> Vibe Studio · build-spec · 모든 작업 묶음이 같이 쓰는 것
> 작성일: 2026-10-16 · 최종 수정일: 2026-10-16
> 기반: docs/PRODUCT.md, docs/FLOWS.md, docs/DESIGN.md, docs/DECISIONS.md

- **스택:** 프로토타입 — Vite + React + TypeScript + Tailwind CSS · 아이콘 Phosphor(`@phosphor-icons/react`) · 글꼴 Pretendard
  - 이유: 먼저 화면 흐름을 눌러보며 확인하고 싶음. 핵심인 캡처 글자 읽기(AI 키 필요)는 첫 버전에서 흉내로 충분함
- **데이터:** 가짜 데이터를 브라우저에 저장(새로고침해도 남게). 미리 써둔 읽기 결과 13건(2026년 10월 13~14일, 그중 같은 결제 1건 → 정리 후 12건), 사용자 1명(카카오 이름 "김콩알"). 붙인 사진도 브라우저에 저장. 진짜 저장소는 나중에
- **흉내만 낼 것:**
  - 캡처 글자 읽기 — 고른 사진 장수만큼 한 장씩 읽는 척하고, 결과는 미리 써둔 내역을 보여줌. 주소에 `?ocr=none`(한 건도 못 읽음) · `?ocr=partial`(1장 실패)을 붙이면 실패 상태를 눌러볼 수 있게
  - 카카오로 시작 — 누르면 "김콩알"로 바로 통과. `?kakao=fail`이면 실패 문구
  - 저녁 알림 — 실제로 보내지 않음. [저녁에 알려주세요]를 누르면 화면 안 안내 문구로 대신. `?notify=blocked`면 알림이 꺼진 상태, `?ios=1`이면 아이폰 홈 화면 추가 안내
  - 홈(달력) — F2에서 그림. F1에선 이번 달 달력 자리만, 기록 있는 날을 누르면 그날 하루 카드
- **이번엔 안 함:** 실제 글자 읽기(AI), 실제 카카오 로그인, 실제 알림 발송, 진짜 저장소, 종이 영수증 사진 인식, 카테고리 자동 분류, 정리 중 나갔다 돌아와 이어보기, 이미 계정 있을 때 기록 합치기, 이메일·애플 로그인, 탈퇴·커플 연결 끊기, 홈 달력 넘겨보기(F2), F3~F5, 확장 아이디어(투자 연동, 대출, 구독, 예산 보드, 소비 리포트, 추억 다시 보기)
- **옮길 때 다시 볼 것** (Next.js로 옮기면 서버로 가야 하는 것): 캡처 글자 읽기(AI 키), 카카오 로그인, 내역·사진 저장
