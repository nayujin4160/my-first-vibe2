## 확정 정보
- **서비스 이름:** 콩알가계부
- **한 줄 무드:** 사실은 또렷하게, 말은 가볍게. 감정은 둘이 알아서 느끼도록 남겨둬요.

## 1. Voice Summary
같은 집에 사는 다정한 살림 메이트처럼 말해요. 귀찮은 정리는 조용히 끝내 두고, 지난 하루는 날짜·장소·금액으로 담백하게 꺼내 줘요.

## 2. Core Personality Traits

**다정한**
- We are: 사용자가 귀찮아하는 걸 먼저 알아채고, 부담을 덜어주는 한마디를 건넨다.
- We are not: 오글거리거나 과하게 애교 부리지 않는다. 사랑·애칭·하트로 다정함을 꾸미지 않는다.
- This sounds like: "비어 있는 날이 있어요. 캡처 한 번에 여러 장 올릴 수 있어요."
- This does NOT sound like: "자기야~ 오늘도 우리 사랑 한 스푼 💕"

**가벼운**
- We are: 문장이 짧고, 사용자에게 시키는 일이 적다. 한 번 읽으면 끝나는 말.
- We are not: 돈 계산은 허술하지 않다. 돈 사정을 놀리거나 자조하는 밈으로 가벼움을 만들지 않는다.
- This sounds like: "캡처 4장에서 12건 정리했어요. 전부 공용에 넣었고, 같은 결제 1건은 뺐어요."
- This does NOT sound like: "텅장 각 ㅋㅋ 이번 달도 망했네요 🙈"

**추억을 아끼는**
- We are: 지난 하루를 날짜·장소·금액·사진 같은 사실로 꺼내 보여주고, "아 맞다" 하는 피식 웃음은 사용자 몫으로 둔다.
- We are not: 매번 감성에 젖지 않는다. 대신 감탄하거나 분위기를 꾸미지 않는다.
- This sounds like: "3월 14일 · 성수동 파스타 38,000원. 이날 사진 3장이 있어요."
- This does NOT sound like: "그날의 햇살과 커피 한 잔, 우리의 소중한 순간을 기억해요…"

**느긋한**
- We are: 밀려도 괜찮다고 말하고, 몰아서 올리는 방식을 환영한다. 알림은 부탁이지 재촉이 아니다.
- We are not: 밀린 기록을 방치하지 않는다. 다만 겁주거나 손해를 들먹이며 몰아붙이지도 않는다.
- This sounds like: "오늘 거 올려볼까요? 캡처 한 장이면 돼요."
- This does NOT sound like: "🔔 오늘 안 올리면 내일 두 배로 귀찮아져요!"

- Formal 3: 부드러운 존댓말 "~해요". 딱딱하지도, 반말로 가깝지도 않게.
- Serious 2: 장난보다 담백함. 웃음은 사실에서 나오게 둔다.
- Peer-level 4: 코치나 선생이 아니라 같이 사는 메이트.
- Simple 5: 생활 말만. 금융 용어 없이.
- Reserved 2: 감탄과 축하는 아껴서.
- Subtle 4: 밀어붙이지 않고 옆에서 조용히.

## 4. Vocabulary Guide

**USE**
- **둘이** — 공용 지출·목표·정산을 말할 때. 한 사람을 주어로 세우지 않고 둘을 함께 묶는다.
- **공용 / 내 용돈 / 내 자산** — 돈의 세 칸을 부르는 이름. 화면·문구에서 똑같이 쓴다.
- **정리했어요** — 업로드 후 자동 입력이 끝났을 때. 우리가 대신 했다는 걸 담백하게 알린다.
- **올려볼까요?** — 기록 알림·빈 상태. 시키지 않고 부탁하는 말.
- **몰아서 올려도 괜찮아요** — 밀린 상태에서. 느긋함을 직접 말한다.
- **캡처 한 장이면 돼요** — 입력 부담을 줄여 말할 때.
- **이날** — 하루 카드에서 지난 날을 가리킬 때.
- **{날짜} · {장소} {금액}** — 하루 카드의 기본 형식. 사실을 먼저 보여준다.
- **사진 N장** — 하루 카드에 남은 기록의 양을 구체적으로.
- **돌려주면 이번 달 끝이에요** — 정산 결과. 누가 누구에게 얼마인지 끝까지 풀어 말한다.
- **N개월 동안 모은 돈이에요** — 목표 달성. 금액·기간·둘을 축으로(상품이 없는 목표도 있으니까).
- **정산** — 월말에 누가 누구에게 얼마인지 맞추는 일.
- **같은 결제 N건은 뺐어요** — 중복 결제를 걸렀을 때. 무엇을 했는지 숫자로 알린다.
- **눌러서 옮겨주세요** — 예외만 사용자에게 맡길 때. 해야 할 동작 하나만 말한다.

**AVOID**
- **텅장 / 거지 / 망했다 / 탕진** — 돈 사정을 놀리거나 자조하는 말. 사용자의 돈을 웃음거리로 만든다.
- **💸 🙈 💕** — 지출을 놀리거나 애정을 과장하는 감정 이모지.
- **자기야 / 우리 사랑 / 달달한** — 오글거리는 커플 앱 말투. 다정함을 넘어선다.
- **소중한 순간 / 그날의 햇살 / 기억해요…** — 감성 일기장 톤. 매번 감상에 젖는 말.
- **OO님이 더 많이 / OO님이 N번 결제했어요** — 둘을 비교하거나 상대 지출을 들추는 말. 한쪽 편을 든다.
- **고마워해야겠어요 / 칭찬해 주세요** — 사용자에게 감정을 시키는 말.
- **혼나요 / 벌금 / 반성** — 혼내는 컨셉. 잔소리 안 하는 살림 메이트와 정반대.
- **안 하면 ~해져요 / 사라져요** — 겁주며 재촉하는 말.
- **N일째 기록이 없어요 / 밀린 내역** — 밀린 부담을 다시 들춘다.
- **지금 바로 / 반드시 / ~하세요** — 명령형·숙제처럼 시키는 말.
- **Balance / Budget / Bills / 잔고 현황** — 영어 금융 용어와 딱딱한 금융 화면 말.
- **처리되었습니다 / 완료되었습니다** — 은행 앱 같은 딱딱한 종결 어미.
- **약 4만 원 / 대략** — 돈 계산을 흐릿하게 만드는 반올림.

## 5. Tone Adaptation Rules

**By Context (앱 안 맥락):**

| 맥락 | 톤 조절 | 예시 문구 |
|------|---------|-----------|
| 온보딩 / 첫 화면 | 다정함을 조금 올리고, 설정할 게 적다는 걸 먼저 말한다. 짧게. | "캡처나 영수증을 올리면 날짜·가게·금액을 정리해 둘게요. 지난 내역은 나중에 몰아서 올려도 돼요." |
| 빈 상태(empty state) | 느긋함을 올린다. 밀렸다고 들추지 않고, 한 번에 올릴 수 있는 방법을 알려준다. | "비어 있는 날이 있어요. 캡처 한 번에 여러 장 올릴 수 있어요." |
| 업로드 정리 완료 | 사실을 숫자로 알리고, 사용자에게 맡길 일은 하나만. | "캡처 4장에서 12건 정리했어요. 전부 공용에 넣었고, 같은 결제 1건은 뺐어요. 용돈으로 옮길 건 눌러서 옮겨주세요." |
| 하루 카드 다시 보기 (말 많이) | 추억을 아끼는 성격을 키우되, 감상 대신 사실을 풍부하게. | "3월 14일 · 성수동 파스타 38,000원. 이날 사진 3장이 있어요." |
| 월말 정산 (말 많이) | 가벼움보다 정확함을 올린다. 누가 누구에게 얼마인지 끝까지 풀어 말하고, 누구 편도 들지 않는다. | "공용통장이 지민에게 127,400원 돌려주면 이번 달 끝이에요." |
| 목표 달성 (말 적게) | 한 줄로. 금액·기간·둘을 축으로, 감탄은 아낀다. | "목표 달성. 둘이 3개월 동안 모은 돈이에요." |
| 에러/안내 (말 많이) | 다정함을 올리고 단정함은 낮춘다. 무엇이 안 됐는지, 왜인지, 어떻게 하면 되는지까지 친절히. | "이 캡처는 금액을 읽지 못했어요. 글자가 흐리거나 잘렸을 수 있어요. 내역이 한 화면에 다 보이게 다시 캡처해서 올려주세요." |
| 푸시 알림 (말 적게) | 가장 짧고 가장 느긋하게. 하루 1번, 부탁하는 말로. | "오늘 거 올려볼까요? 캡처 한 장이면 돼요." |
| 랜딩/소개 페이지 | 가벼움을 올려 짧게. '올리면 끝'과 '둘의 하루'를 사실로 보여준다. | "캡처나 영수증만 올리면 둘의 하루로 정리돼요." |

규칙: 보이스 속성은 고정, 톤은 맥락에 따라 키우거나 줄인다. 푸시·목표 달성은 한 줄로 줄이고, 하루 카드·정산·에러는 사용자가 이해해야 하는 자리라 사실과 설명을 풍부하게 늘린다. 말이 많아지는 자리에서도 감상과 재촉은 늘지 않는다.

## 6. Style Rules
- 존댓말/반말: 부드러운 존댓말 "~해요". "~하십시오", "~합니다"는 쓰지 않는다.
- 문장 길이: 짧고 명료하게. 한 문장에 한 가지만.
- 이모지: 거의 쓰지 않는다. 하루 카드의 음식·장소 정도에만, 한 문구에 최대 1개. 💕🙈💸 같은 감정 이모지는 금지.
- 느낌표: 거의 쓰지 않는다. 목표 달성에서만 최대 1개.
- 숫자: 금액은 "38,000원"처럼 쉼표를 넣어 정확하게. "약 4만 원" 같은 반올림은 쓰지 않는다.
- 호칭: 사용자가 정한 이름 그대로("지민"). "님"은 붙이지 않고, 둘을 함께 말할 때는 "둘이".
- 외래어: 생활 말을 먼저(공용, 용돈, 정산, 목표). 영어 금융 용어는 쓰지 않는다.
- 주어: 공용 지출은 "누가 썼는지"보다 "어디에, 얼마"를 먼저 보여준다.

## 7. Do's and Don'ts

**Do:**
- 날짜·장소·금액·건수·기간 같은 사실을 먼저 말한다.
- 우리가 대신 한 일은 "정리했어요", "뺐어요"처럼 담백하게 알린다.
- 사용자에게 맡길 일은 하나만, 동작으로 말한다("눌러서 옮겨주세요").
- 밀린 상태에서는 몰아서 올려도 괜찮다고 말한다.
- 공용 돈 이야기는 "둘이"로 묶어서 말한다.
- 정산은 누가 누구에게 얼마인지 끝까지 풀어 말한다.
- 목표는 상품이 없을 수도 있으니 금액·기간·둘을 축으로 말한다.
- 에러는 무엇이 안 됐고 어떻게 하면 되는지까지 친절히 알려준다.

**Don't:**
- 감성 일기장처럼 매번 감상에 젖지 않는다.
- 돈 사정을 놀리거나 자조하지 않는다("텅장 ㅋㅋ").
- 둘을 비교하거나 한쪽의 지출을 들추지 않는다.
- 사용자에게 감정을 시키지 않는다("고마워해야겠어요").
- 혼내거나 겁주며 재촉하지 않는다.
- 밀린 날짜 수를 세어 들추지 않는다.
- 영어 금융 용어나 은행 앱 같은 딱딱한 말을 쓰지 않는다.
- 금액을 반올림해서 흐릿하게 말하지 않는다.
