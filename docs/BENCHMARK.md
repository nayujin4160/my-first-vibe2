## 관찰 — 잘하는 점 / 아쉬운 점
- **가계부부**: 잘하는 점 — 8자리 코드 하나로 연결하는 가벼운 시작, 비밀 자산·주체별 통계로 커플의 "따로 또 같이"를 이미 다룬다. 한 명 구독으로 둘 다 혜택. / 아쉬운 점 — 입력은 결국 손으로 해야 한다. 사진은 내역에 붙는 증빙일 뿐 회고의 중심이 아니다. 정산 기능이 보이지 않는다.
- **Honeydue**: 잘하는 점 — Individual / All / Joint 구분과 "공유할 것을 고른다"는 메시지가 명확하다. 지출에 댓글·이모지로 대화하는 커플 감성. / 아쉬운 점 — 미국 은행 연결 전제라 한국에서는 쓸 수 없다. 모바일 웹 첫 화면이 잘린다.
- **BuBoo 부부**: 잘하는 점 — 평가 약 4.6천 개로 국내 커플 가계부 중 규모가 크다. 가계부 + 일정 + 멤버십을 묶어 "부부 생활 앱"을 지향. / 아쉬운 점 — 공식 페이지 기준 수기 입력이고, 개인·공용 구분은 확인되지 않는다.
- **하루조각**: 잘하는 점 — 지출·사진·일정을 하루로 묶어 일기를 대신 써준다는 발상이 우리 하루 카드와 가장 가깝다. / 아쉬운 점 — 개인용이고 공유가 없다. 공식 앱스토어 페이지가 열리지 않아 현재 운영 여부를 확인하지 못했다.
- **Splitwise**: 잘하는 점 — 정산 규칙(균등·비율·지분)과 "Settle up" 흐름이 성숙하다. / 아쉬운 점 — 친구·룸메이트 단위라 커플의 일상 기록·회고 감성은 없다. 영수증 스캔은 유료.

## 우리의 차별 프레이밍  ← 이 리서치의 결론
국내 커플 가계부는 "같이 볼 수 있는 장부"에 머물러 있고, 입력의 귀찮음은 그대로 사용자 몫이다. 해외 커플 앱은 계좌 연결로 입력을 없앴지만 한국에서는 쓸 수 없다. 사진과 소비를 하루로 묶는 앱은 개인용뿐이다. 콩알가계부는 **"올리기만 하면 되는 입력"과 "사진으로 남는 둘의 하루"** 를 함께 가져가, 장부가 아니라 둘이 다시 열어보고 싶은 기록이 된다.

- **빈틈/기회:** 국내 커플 가계부는 모두 손으로 적는 장부이고, 사진은 증빙용으로만 붙는다. 캡처·영수증 자동 인식과 하루 단위 사진 회고를 둘 다 가진 커플 서비스가 없다. 월말 정산도 커플 앱에서는 비어 있다.
- **우리의 자리(포지셔닝):** 귀찮은 커플을 위한, 올리기만 하면 '둘의 하루'로 쌓이는 사진 가계부.
- **차별 포인트:** ① 계좌 연결 없이 캡처·영수증 업로드만으로 입력 ② 사진과 소비가 하루 카드로 쌓이는 회고. 공용/용돈/자산 세 칸과 월말 자동 정산이 이 둘을 받쳐준다.
