첫 캡처 올리기

캡처 한 장 올렸더니, 그날 하루 카드에 날짜·가게·금액이 정리돼 있음 — "오, 진짜 올리기만 하면 되네"

진입 동기
지인 추천이나 SNS에서 "캡처만 올리면 된대"를 보고 링크로 처음 들어옴
상태 변화
"또 귀찮은 가계부겠지" → "올리기만 하면 되는구나"

단계
단계화면기능주 행동핵심 결정
①시작—[캡처 올려보기] → 사진 고르기 → ②소개 슬라이드·가입 없이 버튼 하나. 설정할 게 없다는 걸 첫 화면에서 보여주려고
②정리 중올리면 끝 자동 입력(자동) 다 읽으면 → ③장마다 읽는 진행을 보여줌. 기다리는 동안 무엇을 하는지 보이게
③정리 결과올리면 끝 자동 입력, 세 칸 공유[저장할게요] → ④바로 카드로 보내지 않고 결과 목록을 먼저 보여줌. 전부 공용, 용돈 옮기기·고치기는 줄을 눌러서. 돈 계산은 처음부터 믿을 수 있게
④시작하기(계정)—[카카오로 시작] → ⑤여기서 처음 계정을 물음 + 한 줄 동의. 이름은 카카오 이름을 기본으로
⑤하루 카드하루 카드[이날 사진 붙이기] 또는 [달력 보기] → ⑥올린 내역 중 가장 최근 날의 카드를 바로 열어줌. 사진은 업로드 때 받지 않고 카드에서 한 번 권함. 목표 순간
⑥알림 묻기(시트)기록 알림[저녁에 알려주세요] / [괜찮아요] → 홈(달력)첫 카드를 본 직후에만 물음. 거절해도 몰아서 쓸 수 있다고 말함
화면 상태
화면빈로딩오류
① 시작———
② 정리 중—이 화면 자체가 로딩 상태—
③ 정리 결과한 건도 못 읽음 — "이 캡처는 금액을 읽지 못했어요. 글자가 흐리거나 잘렸을 수 있어요. 내역이 한 화면에 다 보이게 다시 캡처해서 올려주세요."② 정리 중이 대신함일부만 실패 — "1장은 읽지 못했어요" (임시) + [다시 올리기]
④ 시작하기(계정)—카카오에서 돌아오는 동안 버튼에 진행 표시"카카오로 시작하지 못했어요. 잠시 뒤에 다시 눌러주세요." (임시)
⑤ 하루 카드사진 없음 — 점선 사진 자리에 "+ 이날 사진 붙이기"사진 올리는 중 사진 자리를 흐리게"사진을 올리지 못했어요. 연결을 확인하고 다시 눌러주세요." (임시)
⑥ 알림 묻기(시트)——알림 권한이 막혀 있음 — "알림이 꺼져 있어요. 설정에서 켜면 저녁에 알려드려요." (임시)

단계상황어떻게 동작하나
①사진 고르다 취소시작 화면 그대로
①가계부 캡처가 아닌 사진을 올림③에서 "내역을 찾지 못했어요" (임시) 안내 + 다시 올리기
②정리 중 화면을 나감첫 버전은 처음부터 다시 올리기
③금액·가게를 잘못 읽음줄을 눌러 고침 (날짜·가게·금액·공용/용돈)
③같은 결제가 두 장에 겹침자동으로 1건만 남기고 "같은 결제 1건은 뺐어요"
③환불·취소 내역마이너스 금액으로 같이 정리 (정산 반영은 F4)
④계정 만들다 나감정리 결과는 이 기기에 잠깐 들고 있다가, 돌아오면 ③부터
④이미 계정 있음로그인으로 처리, 결과를 기존 기록에 합침 (같은 결제는 걸러냄)
⑥알림 거절"몰아서 올려도 괜찮아요"로 닫고 홈으로. 설정에서 언제든 켬
⑥아이폰 웹 (홈 화면에 추가 안 함)알림을 켜려면 홈 화면 추가가 필요하다고 한 줄 안내
