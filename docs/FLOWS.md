## F1 · 첫 캡처 올리기 — "올리기만 하면 된다며? 진짜?"
> 구분: 첫 방문 · 상태: UI 구현 · 담당 기능: 올리면 끝 자동 입력, 하루 카드(첫 카드), 세 칸 공유(공용 기본값·용돈 옮기기)

**목표 순간**
- 진입 동기: 지인 추천이나 SNS에서 "캡처만 올리면 된대"를 보고 링크로 처음 들어옴
- 목표 순간: 캡처 한 장 올렸더니, 그날 하루 카드에 날짜·가게·금액이 정리돼 있음 — "오, 진짜 올리기만 하면 되네"
- 상태 변화: "또 귀찮은 가계부겠지" → "올리기만 하면 되는구나"

**단계**
| 단계 | 화면 | 기능 | 주 행동 (→ 다음) | 핵심 결정 |
|:--:|------|------|------------------|-----------|
| ① | 시작 | — | [캡처 올려보기] → 사진 고르기 → ② · (보조) "캡처 없이 직접 쓸게요" → 직접 쓰기 → ③ | 소개 슬라이드·가입 없이 주요 버튼 하나. 캡처가 없는 사람도 막히지 않게 글자 버튼으로 직접 쓰기를 둠 |
| ② | 정리 중 | 올리면 끝 자동 입력 | (자동) 다 읽으면 → ③ | 장마다 읽는 진행을 보여줌. 기다리는 동안 무엇을 하는지 보이게 |
| ③ | 정리 결과 | 올리면 끝 자동 입력, 세 칸 공유 | [저장할게요] → ④ | 바로 카드로 보내지 않고 결과 목록을 먼저 보여줌. 읽은 결제 날짜 범위를 맨 위에 한 줄로. 전부 `공용`, 용돈 옮기기·고치기는 줄을 눌러서, 빠진 건 "+ 직접 추가"로 |
| ④ | 시작하기(계정) | — | [카카오로 시작] → ⑤ | 여기서 처음 계정을 물음 + 한 줄 동의. 이름은 카카오 이름을 기본으로 |
| ⑤ | 하루 카드 | 하루 카드 | [이날 사진 붙이기] 또는 [달력 보기] → ⑥ | 올린 내역 중 가장 최근 날의 카드를 바로 열어줌. 사진은 업로드 때 받지 않고 카드에서 한 번 권함. **목표 순간** |
| ⑥ | 알림 묻기(시트) | 기록 알림 | [저녁에 알려주세요] / [괜찮아요] → 홈(달력) | 첫 카드에서 [달력 보기]를 처음 누를 때만 물음. 거절해도 몰아서 쓸 수 있다고 말함 |

**화면**

### ① 시작
```
 ┌───────────────────────────┐
   콩알가계부

   캡처나 영수증을 올리면
   날짜·가게·금액을 정리해 둘게요.
   지난 내역은 나중에 몰아서 올려도 돼요.

   [ 캡처 올려보기 ]
   올린 캡처는 글자를 읽는 데만 써요.
     캡처 없이 직접 쓸게요
 └───────────────────────────┘
```
- **역할:** 설정할 게 없다는 걸 알고 바로 첫 캡처를 올린다. 캡처가 없으면 직접 써서 시작한다.
- **핵심 요소:** 서비스 이름, 소개 문구 두 줄, 화면 아래쪽에 주황 버튼 [캡처 올려보기] 하나(화면의 유일한 주요 행동). 버튼 바로 아래에 회색 작은 글씨로 업로드 안내 한 줄, 그 아래 회색 글자 버튼 "캡처 없이 직접 쓸게요". 로그인 버튼·소개 슬라이드 없음. 버튼을 누르면 기기 사진첩이 열리고 여러 장을 고를 수 있다. 글자 버튼을 누르면 오늘 날짜로 직접 쓰기 시트가 올라오고, [적었어요]를 누르면 ③으로 간다.
- **문구:** "캡처나 영수증을 올리면 날짜·가게·금액을 정리해 둘게요. 지난 내역은 나중에 몰아서 올려도 돼요." · "올린 캡처는 글자를 읽는 데만 써요." · "캡처 없이 직접 쓸게요" (임시)
- **상태:** 해당 없음

### ② 정리 중
```
 ┌───────────────────────────┐
   캡처 4장 중 2장 읽는 중이에요

   ▣ ▣ ▢ ▢     ← 올린 캡처 썸네일, 다 읽은 장은 체크
   ━━━━━━━░░░░░
 └───────────────────────────┘
```
- **역할:** 기다리는 동안 무엇을 하는지 안다.
- **핵심 요소:** 가운데에 진행 문구, 올린 캡처 썸네일이 가로 한 줄로 이어지고 다 읽은 장에는 체크 표시, 아래에 진행 막대. 누를 버튼 없음. 다 읽으면 "캡처 4장을 다 읽었어요"를 잠깐 보여준 뒤 ③으로.
- **문구:** "캡처 4장 중 2장 읽는 중이에요" (임시) · "캡처 4장을 다 읽었어요" (임시)
- **상태:**
  - 로딩: 이 화면 자체가 로딩 상태

### ③ 정리 결과
```
 ┌───────────────────────────┐
   캡처 4장에서 12건 정리했어요.
   10월 11일부터 14일까지의 결제예요.
   전부 공용에 넣었고, 같은 결제 1건은 뺐어요.
   용돈으로 옮길 건 눌러서 옮겨주세요.

   10월 14일 (수)
    성수동 파스타      38,000원  [공용]
    GS25               4,200원  [공용]
   10월 13일 (화)
    올리브영          23,900원  [용돈]
    ...
   ┌ ─ ─ + 직접 추가 ─ ─ ┐

   [ 저장할게요 ]
 └───────────────────────────┘
```
- **역할:** 읽은 내역과 날짜가 맞는지 보고, 예외만 용돈으로 옮기고, 빠진 건 직접 더한다.
- **핵심 요소:** 맨 위 정리 요약 — 건수, **읽은 결제 날짜 범위**, 공용·같은 결제 안내. 그 아래 날짜별로 묶인 목록, 줄마다 가게·금액·`공용`/`용돈` 꼬리표(둘 다 중립색). 줄을 누르면 날짜·가게·금액·공용/내 용돈을 고치는 시트가 올라오고, 고친 줄은 잠깐 연한 주황으로 표시된다. 목록 끝에 점선 테두리 "+ 직접 추가"(직접 쓰기 시트, 날짜는 읽은 날 중 가장 최근 날로 채워짐). 맨 아래 고정된 주황 버튼 [저장할게요]. 목록이 길면 스크롤.
- **문구:** "캡처 4장에서 12건 정리했어요." · "10월 11일부터 14일까지의 결제예요." (임시) · "전부 공용에 넣었고, 같은 결제 1건은 뺐어요. 용돈으로 옮길 건 눌러서 옮겨주세요." · 직접 쓴 게 섞이면 "직접 쓴 1건도 같이 저장해요." (임시) · 직접만 썼으면 제목 "직접 쓴 1건이에요." + "고칠 건 눌러서 고쳐주세요. 저장하면 그날 하루 카드에 들어가요." (임시)
- **상태:**
  - 빈: 한 건도 못 읽음 — "이 캡처는 금액을 읽지 못했어요. 글자가 흐리거나 잘렸을 수 있어요. 내역이 한 화면에 다 보이게 다시 캡처해서 올려주세요." + [다시 올리기] + 글자 버튼 "캡처 없이 직접 쓸게요"
  - 로딩: ② 정리 중이 대신함
  - 오류: 일부만 실패 — 목록 위에 "1장은 읽지 못했어요" (임시) + [다시 올리기]

### 직접 쓰기(시트)
```
 ┌───────────────────────────┐
   직접 쓰기
   [ 공용 | 내 용돈 ]
   날짜  2026-10-16
   가게  예: 성수동 파스타
   금액  ________ 원
   [ 적었어요 ]
 └───────────────────────────┘
```
- **역할:** 캡처가 없는 결제(현금, 계좌이체 등)를 손으로 남긴다.
- **핵심 요소:** 아래에서 올라오는 시트. 공용/내 용돈 고르기(기본 공용), 날짜(여는 자리에 따라 오늘·그날·가장 최근 읽은 날로 채워짐), 가게, 금액(환불은 앞에 -). 가게·금액을 채우면 주황 [적었어요]가 켜진다. 줄 고치기 시트와 같은 모양이고 제목·버튼만 다르다("내역 고치기" · [고쳤어요]).
- **문구:** "직접 쓰기" (임시) · [적었어요] (임시)
- **상태:** 해당 없음

### ④ 시작하기(계정)
```
 ┌───────────────────────────┐
   정리한 12건을 저장할까요?
   카카오로 시작하면 다른 기기에서도 이어서 볼 수 있어요.

   [ 카카오로 시작 ]   ← 카카오 노란색
   시작하면 이용약관과 개인정보 처리에 동의하게 돼요.
 └───────────────────────────┘
```
- **역할:** 방금 정리한 내역을 잃지 않으려고 계정을 만든다.
- **핵심 요소:** 저장할 건수를 말하는 제목 한 줄과 이유 한 줄, [카카오로 시작] 버튼 하나(카카오 로그인 가이드대로 노란색 — DESIGN.md 밖의 색), 그 아래 회색 작은 글씨로 동의 한 줄(약관 링크). 이름은 카카오 이름을 그대로 쓰고 따로 묻지 않는다.
- **문구:** "정리한 12건을 저장할까요?" (임시) · "카카오로 시작하면 다른 기기에서도 이어서 볼 수 있어요." (임시) · "시작하면 이용약관과 개인정보 처리에 동의하게 돼요." (임시)
- **상태:**
  - 로딩: 카카오에서 돌아오는 동안 버튼에 "카카오에서 확인하는 중이에요" (임시)
  - 오류: 카카오 로그인 실패 — "카카오로 시작하지 못했어요. 잠시 뒤에 다시 눌러주세요." (임시)

### ⑤ 하루 카드
```
 ┌───────────────────────────┐
   ‹  10월 14일 (수)  ›
   ┌───────────────────────┐
   │   + 이날 사진 붙이기    │
   └───────────────────────┘
   성수동 파스타      38,000원
   GS25               4,200원
   + 직접 추가
   ─────────────────────────
   이날 공용 42,200원

   [ 달력 보기 ]   ← 회색
 └───────────────────────────┘
```
- **역할:** 올린 캡처가 '그날 하루'로 정리된 걸 처음 본다 — 목표 순간.
- **핵심 요소:** 맨 위에 날짜와 좌우 화살표(기록이 있는 바로 옆 날로 이동, 없으면 흐리게). 그 아래 넓은 사진 자리(비어 있으면 점선 테두리 안에 "+ 이날 사진 붙이기", 붙인 사진을 누르면 다른 사진으로 바꿈). 사진 아래 그날 내역 목록(가게·금액, 용돈은 `용돈` 꼬리표), 줄을 누르면 고치기 시트. 목록 끝에 회색 "+ 직접 추가"(그날 날짜로 직접 쓰기). 구분선 아래 그날 공용 합계(용돈은 빠짐). 맨 아래 회색 [달력 보기] — 사진 붙이기와 달력 보기 중 어느 쪽도 강요하지 않으려고 주황을 쓰지 않음.
- **문구:** "10월 14일 (수)" · "+ 이날 사진 붙이기" (임시) · "+ 직접 추가" (임시) · "이날 공용 42,200원" (임시)
- **상태:**
  - 빈: 사진 없음 — 점선 사진 자리에 "+ 이날 사진 붙이기"
  - 로딩: 사진 올리는 중 사진 자리를 흐리게
  - 오류: 사진 업로드 실패 — "사진을 올리지 못했어요. 연결을 확인하고 다시 눌러주세요." (임시)

### ⑥ 알림 묻기(시트)
```

   (하루 카드가 흐리게 뒤에)
 ┌───────────────────────────┐

   "오늘 거 올려볼까요?" 하고 하루 한 번만 알려드려요.

   [ 저녁에 알려주세요 ]
     괜찮아요
 └───────────────────────────┘
```
- **역할:** 다시 오게 할 계기(저녁 알림)를 받을지 정한다.

- **문구:** "저녁에 알려드릴까요?" (임시) · "'오늘 거 올려볼까요?' 하고 하루 한 번만 알려드려요." (임시) · "몰아서 올려도 괜찮아요." · 아이폰: "아이폰은 홈 화면에 추가해야 알림이 가요." (임시) · 수락 후 홈: "저녁에 '오늘 거 올려볼까요?' 하고 알려드릴게요." (임시)

## F2 · 오늘 거 올리기 — "오늘 뭐 썼더라… 캡처나 올려두자"
> 구분: 다시 오기 · 상태: 기획 완료 · 담당 기능: 기록 알림, 올리면 끝 자동 입력(반복·몰아 올리기), 하루 카드(달력 넘겨보기)

**목표 순간**
- 진입 동기: 저녁에 "오늘 거 올려볼까요?" 알림을 누르거나(하루 마무리형), 일주일·한 달 만에 스스로 열어 몰아 올림(몰아쓰기형). 카카오 로그인이 유지돼서 바로 홈으로 들어온다.
- 목표 순간: 오늘 캡처를 올리고 저장했더니 달력에 오늘 칸이 채워져 있음 — "오늘 것도 끝"
- 상태 변화: "또 적어야 하나" → "올리고 닫으면 되네" (반복의 한 바퀴)

**단계**
| 단계 | 화면 | 기능 | 주 행동 (→ 다음) | 핵심 결정 |
|:--:|------|------|------------------|-----------|
| ① | 홈(달력) | 하루 카드(달력 넘겨보기) | [캡처 올리기] → 사진 고르기 → ② · (보조) "직접 쓰기" → 직접 쓰기 → ③ · 날짜 칸 → 하루 카드 | 돌아왔을 때 첫 화면은 쌓인 달력. 위에 이번 달 공용 합계 한 줄만(그래프·경고 없이). 빈 날도 누르면 열림 |
| ② | 정리 중 | 올리면 끝 자동 입력 | (자동) 다 읽으면 → ③ | F1 ②와 같음 |
| ③ | 정리 결과 | 올리면 끝 자동 입력(반복·몰아 올리기), 세 칸 공유 | [저장할게요] → ① 홈(달력) | F1 ③과 같고, 이미 저장한 결제는 걸러냄. 계정 단계 없이 바로 저장 |
| ④ | 홈(달력) — 채워진 칸 | 하루 카드 | 채워진 칸을 누르면 → 하루 카드 | 저장하면 달력으로 돌아와 새로 채워진 칸을 잠깐 강조. 몰아 올려도 한눈에. **목표 순간** |

**화면**

### ① 홈(달력)
```
 ┌───────────────────────────┐
   ‹  2026년 10월  ›          ⚙
   이번 달 공용 238,520원
   일 월 화 수 목 금 토
             1  2  3
   ...
   11 12 [13] 14 15 (16) 17
   ·  ·  사진 ·
   ...
   [ 캡처 올리기 ]
       직접 쓰기
 └───────────────────────────┘
```
- **역할:** 돌아오자마자 이번 달이 어떻게 채워졌는지 보고, 오늘 거를 올린다.
- **핵심 요소:** 맨 위에 달 이름과 좌우 화살표(지난달·다음 달, 이번 달보다 뒤는 흐리게), 오른쪽 끝에 설정 톱니. 그 아래 회색 한 줄 "이번 달 공용 N원"(내 용돈은 빠짐). 그 아래 7칸 달력 — 사진을 붙인 날은 사진이 칸을 채우고, 기록만 있는 날은 숫자 아래 작은 점, 빈 날은 숫자만, 오늘은 숫자에 테두리. 모든 날짜 칸을 누를 수 있다(빈 날은 빈 하루 카드). 맨 아래 고정된 주황 [캡처 올리기](화면의 유일한 주요 행동), 그 아래 회색 글자 버튼 "직접 쓰기"(오늘 날짜로 직접 쓰기 시트).
- **문구:** "2026년 10월" · "이번 달 공용 238,520원" (임시) · [캡처 올리기] (임시) · "직접 쓰기" (임시)
- **상태:**
  - 빈: 이번 달 기록이 아직 없음 — 달력 위에 "이번 달은 아직 비어 있어요. 캡처 한 번에 여러 장 올릴 수 있어요." (임시), 합계 줄은 숨김
  - 로딩: 달력 칸을 옅은 회색으로 먼저 그림
  - 오류: 기록을 불러오지 못함 — "연결이 잠깐 끊겼어요. 다시 눌러주세요." (임시)

### 설정
```
 ┌───────────────────────────┐
   ‹ 설정
   저녁 알림        [ 켬 ]
   김콩알 · 카카오
   로그아웃
 └───────────────────────────┘
```
- **역할:** 알림을 켜고 끄거나 로그아웃한다.
- **핵심 요소:** 저녁 알림 켬/끔 스위치(켜면 F1 ⑥과 같은 권한 확인, 아이폰은 홈 화면 추가 안내), 카카오 이름 한 줄, 로그아웃 글자 버튼. 탈퇴·연결 끊기는 없음.
- **문구:** "저녁 알림" (임시) · "로그아웃" (임시)
- **상태:**
  - 오류: 알림 권한이 막혀 있음 — F1 ⑥ 참고

### ② 정리 중
- → F1 ② 참고. 달라지는 점 없음.

### ③ 정리 결과
- → F1 ③ 참고. 달라지는 점:
  - 이미 저장한 결제(날짜·가게·금액이 같음)는 걸러내고 요약에 "이미 올린 결제 2건은 뺐어요." (임시)
  - [저장할게요]를 누르면 계정을 묻지 않고 바로 저장하고 ④로.
  - 읽은 결제가 모두 이미 저장된 것이면 — "이미 올린 결제예요. 새로 넣을 내역은 없어요." (임시) + [홈으로] (임시)

### ④ 홈(달력) — 채워진 칸
- → F2 ① 참고. 달라지는 점: 방금 채워진 날짜 칸을 잠깐 연한 주황(brand-tint)으로 강조하고, 아래에 안내가 잠깐 뜬다. 여러 날이 채워졌으면 그 날들을 모두 강조하고, 저장한 결제 중 가장 최근 날의 달을 보여준다.
- **문구:** 하루면 "10월 16일이 채워졌어요." (임시) · 여러 날이면 "3일이 채워졌어요." (임시)

### 하루 카드 (F2에서 열 때)
- → F1 ⑤ 참고. 달라지는 점: 달력에서 빈 날을 누르면 빈 하루 카드가 열린다 — 내역 자리에 "이날은 아직 비어 있어요. 캡처 한 장이면 돼요." (임시)와 "+ 직접 추가". [달력 보기]를 눌러도 알림은 다시 묻지 않는다. 화살표는 기록 있는 옆 날로.

| ③ | 이미 올린 결제와 겹침 | 걸러내고 "이미 올린 결제 N건은 뺐어요" |
| ③ | 지난달 결제가 섞임 | 그 날짜 칸에 들어감. 저장 후엔 가장 최근 날의 달을 보여줌 |
| 하루 카드 | 빈 날을 열었다가 아무것도 안 하고 나감 | 칸은 빈 그대로 |
| 전체 | 연결 끊김 | "연결이 잠깐 끊겼어요. 다시 눌러주세요." (임시) 올린 캡처는 유지 |

**첫 버전 범위**
- 넣음: 홈 달력(달 넘기기, 이번 달 공용 합계, 사진·점 칸, 빈 날 열기), [캡처 올리기]·직접 쓰기, 이미 올린 결제 거르기, 저장 후 채워진 칸 강조, 빈 하루 카드, 설정(저녁 알림 켬·끔, 로그아웃)
- 나중에: 알림 시간 고르기, 달력에서 날짜를 길게 눌러 바로 올리기, 이번 달 돌아보기 요약(→ F4), 하루 사진 여러 장

**건너뛴 기본값:** 알림을 누르면 홈(달력)으로 — 웹에서는 사진첩을 자동으로 열 수 없어서 · 홈 합계는 공용만(내 용돈 제외) · 다음 달 화살표는 이번 달에서 멈춤 · 오늘 칸은 테두리로만 표시(주황 안 씀) · 설정은 홈 오른쪽 위 톱니 하나
