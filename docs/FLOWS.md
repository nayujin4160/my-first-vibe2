## F1 · 첫 캡처 올리기 — "올리기만 하면 된다며? 진짜?"
> 구분: 첫 방문 · 상태: 기획 완료 · 담당 기능: 올리면 끝 자동 입력, 하루 카드(첫 카드), 세 칸 공유(공용 기본값·용돈 옮기기)

**목표 순간**
- 진입 동기: 지인 추천이나 SNS에서 "캡처만 올리면 된대"를 보고 링크로 처음 들어옴
- 목표 순간: 캡처 한 장 올렸더니, 그날 하루 카드에 날짜·가게·금액이 정리돼 있음 — "오, 진짜 올리기만 하면 되네"
- 상태 변화: "또 귀찮은 가계부겠지" → "올리기만 하면 되는구나"

**단계**
| 단계 | 화면 | 기능 | 주 행동 (→ 다음) | 핵심 결정 |
|:--:|------|------|------------------|-----------|
| ① | 시작 | — | [캡처 올려보기] → 사진 고르기 → ② | 소개 슬라이드·가입 없이 버튼 하나. 설정할 게 없다는 걸 첫 화면에서 보여주려고 |
| ② | 정리 중 | 올리면 끝 자동 입력 | (자동) 다 읽으면 → ③ | 장마다 읽는 진행을 보여줌. 기다리는 동안 무엇을 하는지 보이게 |
| ③ | 정리 결과 | 올리면 끝 자동 입력, 세 칸 공유 | [저장할게요] → ④ | 바로 카드로 보내지 않고 결과 목록을 먼저 보여줌. 전부 `공용`, 용돈 옮기기·고치기는 줄을 눌러서. 돈 계산은 처음부터 믿을 수 있게 |
| ④ | 시작하기(계정) | — | [카카오로 시작] → ⑤ | 여기서 처음 계정을 물음 + 한 줄 동의. 이름은 카카오 이름을 기본으로 |
| ⑤ | 하루 카드 | 하루 카드 | [이날 사진 붙이기] 또는 [달력 보기] → ⑥ | 올린 내역 중 가장 최근 날의 카드를 바로 열어줌. 사진은 업로드 때 받지 않고 카드에서 한 번 권함. **목표 순간** |
| ⑥ | 알림 묻기(시트) | 기록 알림 | [저녁에 알려주세요] / [괜찮아요] → 홈(달력) | 첫 카드를 본 직후에만 물음. 거절해도 몰아서 쓸 수 있다고 말함 |

**화면**

### ① 시작
```
 ┌───────────────────────────┐
   콩알가계부

   캡처나 영수증을 올리면
   날짜·가게·금액을 정리해 둘게요.
   지난 내역은 나중에 몰아서 올려도 돼요.

   [ 캡처 올려보기 ]
   올린 캡처는 글자를 읽는 데만 써요.
 └───────────────────────────┘
```
- **역할:** 설정할 게 없다는 걸 알고 바로 첫 캡처를 올린다.
- **핵심 요소:** 서비스 이름, 소개 문구 두 줄, 화면 아래쪽에 주황 버튼 [캡처 올려보기] 하나(화면의 유일한 주요 행동). 버튼 바로 아래에 회색 작은 글씨로 업로드 안내 한 줄. 로그인 버튼·소개 슬라이드 없음. 버튼을 누르면 기기 사진첩이 열리고 여러 장을 고를 수 있다.
- **문구:** "캡처나 영수증을 올리면 날짜·가게·금액을 정리해 둘게요. 지난 내역은 나중에 몰아서 올려도 돼요." · "올린 캡처는 글자를 읽는 데만 써요."
- **상태:** 해당 없음

### ② 정리 중
```
 ┌───────────────────────────┐
   캡처 4장 중 2장 읽는 중이에요

   ▣ ▣ ▢ ▢     ← 올린 캡처 썸네일, 다 읽은 장은 체크
   ━━━━━━━░░░░░
 └───────────────────────────┘
```
- **역할:** 기다리는 동안 무엇을 하는지 안다.
- **핵심 요소:** 가운데에 진행 문구, 올린 캡처 썸네일이 가로 한 줄로 이어지고 다 읽은 장에는 체크 표시, 아래에 진행 막대. 누를 버튼 없음.
- **문구:** "캡처 4장 중 2장 읽는 중이에요" (임시)
- **상태:**
  - 로딩: 이 화면 자체가 로딩 상태

### ③ 정리 결과
```
 ┌───────────────────────────┐
   캡처 4장에서 12건 정리했어요.
   전부 공용에 넣었고, 같은 결제 1건은 뺐어요.
   용돈으로 옮길 건 눌러서 옮겨주세요.

   10월 14일 (화)
    성수동 파스타      38,000원  [공용]
    GS25               4,200원  [공용]
   10월 13일 (월)
    올리브영          23,900원  [공용]
    ...

   [ 저장할게요 ]
 └───────────────────────────┘
```
- **역할:** 읽은 내역이 맞는지 보고, 예외만 용돈으로 옮긴다.
- **핵심 요소:** 맨 위 정리 요약 세 줄. 그 아래 날짜별로 묶인 목록, 줄마다 가게·금액·`공용` 꼬리표. 줄을 누르면 날짜·가게·금액·공용/용돈을 고치는 시트가 올라온다. 맨 아래 고정된 주황 버튼 [저장할게요]. 목록이 길면 스크롤.
- **문구:** "캡처 4장에서 12건 정리했어요. 전부 공용에 넣었고, 같은 결제 1건은 뺐어요. 용돈으로 옮길 건 눌러서 옮겨주세요."
- **상태:**
  - 빈: 한 건도 못 읽음 — "이 캡처는 금액을 읽지 못했어요. 글자가 흐리거나 잘렸을 수 있어요. 내역이 한 화면에 다 보이게 다시 캡처해서 올려주세요."
  - 로딩: ② 정리 중이 대신함
  - 오류: 일부만 실패 — 목록 위에 "1장은 읽지 못했어요" (임시) + [다시 올리기]

### ④ 시작하기(계정)
```
 ┌───────────────────────────┐
   정리한 12건을 저장할까요?

   [ 카카오로 시작 ]
   시작하면 이용약관과 개인정보 처리에 동의하게 돼요.
 └───────────────────────────┘
```
- **역할:** 방금 정리한 내역을 잃지 않으려고 계정을 만든다.
- **핵심 요소:** 저장할 건수를 말하는 제목 한 줄, [카카오로 시작] 버튼 하나, 그 아래 회색 작은 글씨로 동의 한 줄(약관 링크). 이름은 카카오 이름을 그대로 쓰고 따로 묻지 않는다.
- **문구:** "정리한 12건을 저장할까요?" (임시) · "시작하면 이용약관과 개인정보 처리에 동의하게 돼요." (임시)
- **상태:**
  - 로딩: 카카오에서 돌아오는 동안 버튼에 진행 표시
  - 오류: 카카오 로그인 실패 — "카카오로 시작하지 못했어요. 잠시 뒤에 다시 눌러주세요." (임시)

### ⑤ 하루 카드
```
 ┌───────────────────────────┐
   ‹  10월 14일 (화)  ›
   ┌───────────────────────┐
   │   + 이날 사진 붙이기    │
   └───────────────────────┘
   성수동 파스타      38,000원
   GS25               4,200원
   ─────────────────────────
   이날 공용 42,200원

   [ 달력 보기 ]
 └───────────────────────────┘
```
- **역할:** 올린 캡처가 '그날 하루'로 정리된 걸 처음 본다 — 목표 순간.
- **핵심 요소:** 맨 위에 날짜와 좌우 화살표(전날·다음날). 그 아래 넓은 사진 자리(비어 있으면 점선 테두리 안에 "+ 이날 사진 붙이기"). 사진 아래 그날 내역 목록(가게·금액), 구분선 아래 그날 공용 합계. 맨 아래 [달력 보기].
- **문구:** "10월 14일 (화)" · "+ 이날 사진 붙이기" (임시) · "이날 공용 42,200원" (임시)
- **상태:**
  - 빈: 사진 없음 — 점선 사진 자리에 "+ 이날 사진 붙이기"
  - 로딩: 사진 올리는 중 사진 자리를 흐리게
  - 오류: 사진 업로드 실패 — "사진을 올리지 못했어요. 연결을 확인하고 다시 눌러주세요." (임시)

### ⑥ 알림 묻기(시트)
```
 ┌───────────────────────────┐
   (하루 카드가 흐리게 뒤에)
 ┌───────────────────────────┐
   저녁에 알려드릴까요?
   "오늘 거 올려볼까요?" 하고 하루 한 번만 알려드려요.
   몰아서 올려도 괜찮아요.

   [ 저녁에 알려주세요 ]
     괜찮아요
 └───────────────────────────┘
```
- **역할:** 다시 오게 할 계기(저녁 알림)를 받을지 정한다.
- **핵심 요소:** 하루 카드 위로 아래에서 올라온 시트(뒤 화면은 흐리게). 제목, 설명 두 줄, 주황 버튼 [저녁에 알려주세요], 그 아래 글자 버튼 [괜찮아요]. 아이폰 웹에서 홈 화면에 추가하지 않았으면 설명 아래 홈 화면 추가 안내 한 줄.
- **문구:** "저녁에 알려드릴까요?" (임시) · "'오늘 거 올려볼까요?' 하고 하루 한 번만 알려드려요." (임시) · "몰아서 올려도 괜찮아요." · 아이폰: "아이폰은 홈 화면에 추가해야 알림이 가요." (임시)
- **상태:**
  - 오류: 알림 권한이 막혀 있음 — "알림이 꺼져 있어요. 설정에서 켜면 저녁에 알려드려요." (임시)

**예외**
| 단계 | 상황 | 어떻게 동작하나 |
|:--:|------|----------------|
| ① | 사진 고르다 취소 | 시작 화면 그대로 |
| ① | 가계부 캡처가 아닌 사진을 올림 | ③에서 "내역을 찾지 못했어요" (임시) 안내 + 다시 올리기 |
| ② | 정리 중 화면을 나감 | 첫 버전은 처음부터 다시 올리기 |
| ③ | 금액·가게를 잘못 읽음 | 줄을 눌러 고침 (날짜·가게·금액·공용/용돈) |
| ③ | 같은 결제가 두 장에 겹침 | 자동으로 1건만 남기고 "같은 결제 1건은 뺐어요" |
| ③ | 환불·취소 내역 | 마이너스 금액으로 같이 정리 (정산 반영은 F4) |
| ④ | 계정 만들다 나감 | 정리 결과는 이 기기에 잠깐 들고 있다가, 돌아오면 ③부터 |
| ④ | 이미 계정 있음 | 로그인으로 처리, 결과를 기존 기록에 합침 (같은 결제는 걸러냄) |
| ⑥ | 알림 거절 | "몰아서 올려도 괜찮아요"로 닫고 홈으로. 설정에서 언제든 켬 |
| ⑥ | 아이폰 웹 (홈 화면에 추가 안 함) | 알림을 켜려면 홈 화면 추가가 필요하다고 한 줄 안내 |
